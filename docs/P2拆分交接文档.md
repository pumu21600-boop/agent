## 六、施工纪律与坑(原 agent 踩实过的,必读)

**1. 巨石动刀三步缺一不可**(件 2 盲切翻车 / 件 3 首拆 E0616 七连的根因都在跳步):
   - ① Cartographer 预盘点:node 分块脚本(顶层条目 + 前置属性/文档行归位,**无缝分区**)→ 报告**落盘** → `wc -l` 对账 → Read 通道核对。**绝不信任控制台中文回显**(GBK/UTF-8 串扰,本会话两次因此误判);
   - ② 共享根定态:**类型定义与 impl 块留 mod.rs 根**(Rust 字段隐私对定义模块的后代全开,子域都是根的后代 → **零字段手术**),只搬自由函数:子文件首行 `use super::*;`,顶层项 pub(crate) 化;
   - ③ 可见性收口:**`pub(super)` 语义随层级漂移**——chat.rs(server 的子级)的 `pub(super)` 搬进 `chat/` 孙级后降为"chat 内可见",headless.rs 七处 E0616 即此;统一 `pub(super)`→`pub(crate)` 重写,**含搬移结构体定义块的字段行**(正则须匹配 `^    (pub\(super\) )?[a-z_]+: `,只匹配裸字段会漏掉带前缀的);
2. **node 脚本回显必须与磁盘对账**:`wc -l`/`ls` 验证产物在盘;回显成功但产物缺失 = 通道伪造信号,停手如实报;
3. **通道可能出现伪造回显与幻影操作**(本会话实锤:幽灵 Edit、互相矛盾的 git log、幻影工具调用、把两个文件的分区报告互相镜像)——一切以 git 与磁盘为准;矛盾时停手报告,不赌;

5. **脚本用 Write 工具直落磁盘**(heredoc 有反斜杠/引号吞噬与内容漂移史;node -e 代码串里的 /tmp 路径不吃 MSYS 翻转,argv 传参才吃);

9. **盘点脚本(现成,`node part.js <源文件> <报告路径>` 调用)**:

```js
const fs = require('fs');
const L = fs.readFileSync(process.argv[2], 'utf8').split(/\r?\n/);
const isM = s => /^(pub(\([^)]*\))? )?(struct|enum|impl|fn|async fn|const|static|mod|use )|^#\[cfg\(test\)\]/.test(s);
const isA = s => /^\s*(#\[|\/\/\/)/.test(s);
const st = [];
for (let i = 0; i < L.length; i++) {
  if (!isM(L[i])) continue;
  let s = i;
  while (s > 0 && isA(L[s - 1])) s--;
  st.push({ st: s + 1, sig: L[i].slice(0, 60) });
}
const O = ['lines=' + L.length + ' blocks=' + st.length];
for (let k = 0; k < st.length; k++) {
  const e = (k + 1 < st.length ? st[k + 1].st - 1 : L.length);
  O.push('B' + k + ' ' + st[k].st + '-' + e + ' | ' + st[k].sig);
}
fs.writeFileSync(process.argv[3], O.join('\n'), 'utf8');
console.log('done lines=' + L.length + ' blocks=' + st.length);
```
