16. **体积星云的坑**（P14 三轮返工，改 `web/src/galaxy/` 前必读）：
    - **sampler 必须写精度**：GLSL ES 3.0 里 `sampler3D`/`sampler2D` 没有默认精度，写成 `uniform highp sampler3D uNoise;`，否则编译报 "No precision specified"（会被前端兜底逻辑吞成"WebGL2 不可用"，看状态条才能发现）。
    - **步长要按场景尺度归一**：体积积分里 `dt` 直接用世界单位时，密度系数会随场景半径数量级失控（一次调参就把整团云曝成白球）；统一用 `dt/uRadius`。
    - **颜色必须分属不同结构**：把互补色当作同一团丝的"变色"（丝脊换补色）= 青与品红沿视线积累 → 混成灰白（同色实验证明着色链路没问题）。参考图的青气/橙尘/品红核是**三套独立的 ridged 场**，各自取样、各自配色、尘埃还负责吸光。
    - **包络要强**：团簇包络弱了（exp 系数 1.4）一条视线会穿多团，颜色沿途平均成灰褐；系数 2.1 以上保证一线 1-2 团。
    - **体渲染锐度有物理上限**：44 步积分的步长 ≈ 64³ 纹理最细特征，丝永远偏糊；解法是**合成通道里叠屏幕空间细丝**（2D ridged fbm + 低频域扭曲拉流向 + 染色跟随底色 + 以视线方向/uZoom 锚定），照片感来自后期而非无限加密体积采样。
    - **烘焙基函数进纹理**：把 R/G/B/A 四通道做成 4 种基（fbm/脊络/中频折痕/高频毛刺）而不是 4 个八度的同种噪声——abs 折痕是 V 形锐利的，一次采样同时拿到四种结构素材。
    - **尘埃的配比决定观感**：尘埃发光调低 + 消光调高 = 暗剪影，青气才压得住场；配反了就是一滩黄泥。
    - **PS 修改文件用 `[IO.File]::ReadAllText/WriteAllText` + 显式 UTF8**：`Get-Content|Set-Content` 默认走系统 ANSI（GBK），UTF-8 中文会被读成乱码再写坏（Galaxy.svelte 曾整文件报废重写）。
    - **恒星"看不见"先查 `gl_PointSize` 尺寸公式**（`aSize*(H/2/tanFov)/z`，与相机 z 同阶），不是没画——调试：临时把尺寸乘大系数。
    - **布局半径别线性累加**：单会话小项目会把后续团线性推远、星云散成孤岛；用 `max(累加, 460*√i)` 次线性增长。
    - **调参只能小步走（P14 五轮教训）**：尘埃发光/消光与空腔掩膜频率一次动两个档位以上，就从"参考图"翻到"海绵/黄泥"（第四轮橙尘 emission 1.45→2.6 + 消光 5.2→3.0 + 空腔频率 0.40→0.30 三处一起动，全画面翻车）；一轮只动一组参数，截图对比再走。
    - **团状大理石纹的解法是流向拉伸 + 空腔掩膜**：ridged 场 + 强域形变会出闭合漩涡（玛瑙/指纹感）；把采样域沿低频方向场各向异性压扁（沿流向 0.40、垂直 2.0）丝缕变细长烟帘，低频 fbm 掩膜（freq≈0.38，留 10% 底）打破满球剪影、出非对称瓣和大暗腔。
    - **恒星"刺眼"的根源是 sprite 基础尺寸 + 白晕**（P14 六轮：会话星 95+32·size 的基础尺寸让每颗星糊成 130-240px 白球）：会话星压到 20+8·size、glow 0.60→0.34、halo 0.26→0.10、外晕纯 vColor 不掺白——恒星只是锐利小光点，大面积泛光的是云。
    - **品红核要"颗粒结"不要"平滑光球"**：半径收到 0.58σ、高频毛刺(A)通道打颗粒（grain 0.30+0.70·smoothstep(s.a)）、白热只留极中心（hot mix ≤0.32），否则中心又是一块奶油饼。
    - **宽橙帘要用"青气互补门控"**：单靠折痕线(B)只有细线；补一层低频折痕场大块高值区当宽帘，但必须乘 (1-smoothstep(0.25,0.60,s.g)) 让橙只长在气的间隙——没有门控就是全画面橙斑（发霉感）。
    - **照片感的最后一层是分级**：只对蓝主导像素做冷色深化（isBlue 门控 ×vec3(0.86,0.96,1.16)），暗腔底给深蓝余光而不是纯黑，亮脊顶 mix 白热——整体蓝调才对得上参考图。
    - **云中视角（相机 0.45×sceneRadius）三条铁律**（P14 七轮）：① 屏幕空间的"大尺度暗腔"在云内视角会变成满屏豹纹（形状恒定、与视差无关，一眼假）——降到 0.55 底的轻微暗示，暗部交给体积层的暗尘带；② 特征被放大 ~2 倍，噪声采样频率同比抬高（1.7→2.4）；③ 长路径积累会把中等噪声值糊成"棉花底"——smoothstep(0.46,0.94) 掐掉全部中值只留脊尖，脊间压黑。
    - **暗尘带用低频脊络反向做，不用阈值化 fbm**：fbm 阈值出孤立圆斑（迷彩），脊络天然连片沿折痕走向（lane = G@0.45freq，env ×= 1-0.78·smoothstep(0.55,0.90,lane)）——参考图的暗部是连成片的尘墙。
    - **高频域形变 = 揉皱锡纸**：两级 warp 强度（0.9/0.5）会把脊络场闭成小环，满屏"褶皱纸"（用户：更奇怪了）；压到 0.55/0.30 只留大尺度卷曲，配流向拉伸出长弧丝缕。屏幕空间的丝纹 mask 也必须跟亮度走（smoothstep(0.10,0.35,lum)），在暗区刷丝会把黑底抹成均匀中灰。
    - **"纹理感太强"的总解 = 柔雾层 + 大形态（P14 八轮）**：全部锐化丝线 = 雕刻版画，没有"星云飘散"感。气体必须分两层——柔雾体（fbm 低频、无锐化、占主导）+ 丝缕（嵌在雾里、跟随暗尘带分布 fil×(0.3+0.7·smoothstep(0.40,0.78,lane))）；采样频率宁小勿大（1.15，大形态占画面 1/5~1/3，细节只是次级调制）。多轮拉锯结论：结构"太锐/太密"永远比"太柔/太大"更难看，往柔里调不会错。
    - **"为什么非要弄那些线"（P14 八轮用户原话，终审结论）**：所有"线"都来自同一条流水线——ridged 噪声（数学本质 = 沿噪声极大值描等高线）+ 阈值/pow 锐化 → 只剩线活着；体积里如此，屏幕空间刻丝也如此，全删。**自然云雾的正确配方**：`field = fbm低频·0.82 + 脊络·0.12 - 高频毛刺·0.20`（减高频 = 侵蚀边缘啃出絮状），`body = env · smoothstep(0.18,0.58,field)`（smoothstep 带出"形"，边缘是渐变带不是线），体色随亮度渐变（深蓝→青→白）。两个极端都翻过车：全描线（用户否）、纯 fbm 无带（失焦光斑）；渲染分辨率下限 0.42（0.3 再放大本身就"失焦"）。
    - **P14 终版架构 = 离线烘焙（借鉴 wwwtyro/space-3d，Unlicense）**：用户终拍板"不要纹理"。每帧光线步进的细节密度有物理上限，改为打开视图时把星云一次性烘进 3×2 cubemap 图集（位移迭代噪声 = 6 步域位移 + 经典 4D Perlin，多层颜色/尺度/强度/衰减 alpha 叠加），运行时视线与巨壳（6×sceneRadius）求交采样——每帧成本从 44 步积分降到 1 次纹理采样。团辉光在采样时按团方向叠同色高斯（星云与数据仍对应）。烘焙要点：① `gl_FragCoord` 是窗口坐标不是视口坐标，图集分面必须传视口原点校正（否则 2~6 号面采错区域、面间硬缝）；② 位移迭代噪声输出集中在 0.5 附近（方差小），intensity 1.5~1.9 放大 + falloff 4~20 切云块；③ scale 决定形态占比（~1.0 = 一块云约 1/5 天球，0.3 = 半球一块 → 必糊）；④ **分层顺序即合成顺序：蓝气 → 橙纱（高衰减只留亮块）→ 暗尘带压轴**——压轴暗层在蓝、橙上都刻近黑暗带；没有压轴暗层，蓝+橙覆盖并集填满整屏（无黑场=不像照片）；⑤ 默认相机方位对着烘焙完成后的"蓝气主体"方向选（az 3.6）；⑥ **壳半径必须动态跟随相机**：`radius = max(6×sceneRadius, |camPos|×1.6)`（P14 十轮用户实拍"最外围有个球"）——平移上限是按轴算的，斜向 2.5×√3 ≈ 4.3×，再加拉远 4.5×，组合位置必然超过任何静态壳；相机一出壳，星空里就悬着一颗贴图球（截图实锤）。动态壳让相机在几何上永远在壳内，且壳变大不改变采样方向分布（方向场连续无跳变）。
⑦ 深蓝底层 falloff 别低于 ~4.5：覆盖满球没有黑场 = 同样读成行星表面；⑧ **合成通道的圆形暗角必须删**：星云铺满画面后"中间亮四周黑"的圆形渐晕 = 整个屏幕读成一颗球（P14 九轮用户："还是个球"），参考照片没有暗角、星到边；⑨ 单层大圆橙团同理读成行星：橙层 scale ≥2.3 + falloff ≥19 打成小碎块；⑩ **团辉光必须压到若隐若现**（falloff ≥40、强度 ≤0.12）：最大项目团的辉光在暗背景上就是一颗巨大的青色圆盘（P14 十轮用户实拍"圆形画面"）——任何"径向渐变光斑"在暗背景上都会被读成球；⑪ **平移限幅必须向量限长 + 密度滑条保住暗尘带**（P14 十一轮用户："往上下左右还有一堆没光点的星云空间"）：平移按轴限幅时斜向组合跑出星场（2.5×√3 ≈ 4.3 倍），云外全是无星区——改为目标向量限长 0.45×fieldR（fieldR=buildScene 返回的光点散布半径）；拉远上限单独定 2.8×fieldR（缩到最小要一眼看全所有光点，见 ⑫）；密度滑条调低时暗尘带层保底 max(0.72, density)——黑场是构图的一半，不能跟着密度一起消失。**测试必须覆盖平移到上下左右限幅的状态，不能只测默认视角**；⑫ **拉远上限 = 2.8×fieldR，不是"越近越好"**（P14 十二轮）：用户否了 0.85×——缩到最小必须一眼看全所有光点。经验公式：拉远上限 ≈ 星场半径 / tan(垂直半视角) ≈ fieldR/0.445 ≈ 2.25×fieldR，取 2.8×fieldR 留余量；"有云无星空区"由平移限幅负责（拉远看向星场中心，不产生空区），两个限幅各管一件事，别混。
17. **临时实例真机验证三步坑**（P16/024 踩过）：① `agent.exe` **无参双击分支**在已有兄弟 agent.exe 进程时直接退出（只开浏览器、不起服务）——临时实例必须 `agent.exe --minimized` 显式起；② 应用根（exe 同级）除 `config.toml` 外还必须放 `providers.json`（缺了启动即 `Error: 读 providers.json 失败`），`prompts/` 缺失只会回落到兜底提示词；③ 本机 shell 环境带 `http_proxy=http://127.0.0.1:7897`，curl 打本地端口会被代理拦成 502（`--noproxy '*'` 才直连；`env | grep -i proxy` 可能看不到，看 `curl -v` 的 "Uses proxy env variable"）。完整流程：临时目录 = exe + config.toml（独立端口）+ providers.json + prompts/，mock 渠道 `node scripts/mock_provider.mjs`（9399，剧本「慢流」= 30 片 × 300ms），验证完只杀临时目录里的 PID（用户常驻 release 进程别碰）。④ **eval CLI 打本地服务必须先设 `NO_PROXY=127.0.0.1,localhost`**（2026-09-23 实测）：reqwest 在 Windows 上会读系统代理注册表，环回请求被代理接走返 **502**，而 curl 不读注册表所以直连正常——「curl 通但 eval 报 502」不是服务问题，别往渠道/配置方向排查。另：本机 Bash 工具链会把命令行里的 `Bearer <key>` 字面量脱敏成占位符，验证渠道鉴权时用变量展开（`-H "Authorization: Bearer $KEY"`），否则会误判「渠道不认 Bearer」（StepFun step_plan 实测标准 Bearer 可用）。
18. **壳的 child webview 禁用 `set_bounds`**（P20.4 补丁四 A/B 实锤）：`Webview::set_bounds`（位置+尺寸一条用户消息）在部分时序下会把子 webview 的 CDP target 直接搞掉——症状是标签建出来十几毫秒后被 `reap_dead_tabs` 当死 tab 收割（JSONL `browser.stale` reason=tabs-dead、面板里一个标签都留不住），且 `/json/list` 里看不到子 webview。搬位置/尺寸一律用 `set_position` + `set_size` 两条（wry 走 SetWindowPos NOZORDER，不动层级也稳）。另：**透明 child webview 不注册 `/json/list`**（CDP 目标发现要浏览器级 `Target.getTargets` 才看得见），调试壳内浮层时别被 `/json/list` 骗了。
