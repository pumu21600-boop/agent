## 目标

1. **插件契约 v1（二合一）**：一份 manifest.json 统一定义插件——`apiVersion` + `source` + `permissions` + 面板声明 + 工具声明；解析忽略未知字段，`apiVersion` 不匹配拒载并在 UI 提示升级。现有 ui-ext 与 plugins 两种形态迁入统一定义（老目录自动迁移读入，不丢能力）。「扩展」「WASM 插件」术语在 README / 设置 UI / 用户可见文案中退役；MCP 保持独立层不动。
2. **存储收进一门**：新建统一存储入口模块，先收**会话**与 **settings** 两大高频写点（仓内不得再有绕过入口的这两类落盘）；插件侧只有只读 API + 自己命名空间内的结构化写；内核保留区（会话/设置/记忆/检查点）插件写不进，拒绝落 JSONL 审计。
3. **钩子接口 v1**：四个挂点 `before_tool` / `after_tool` / `session_end` / `budget_exceeded`；`before_tool` 有否决权、**无放行权**（不得绕过审批门）；挂点限时，超时视为放行不卡主循环；触发与结果记 JSONL（只增 kind）。
4. **插件生命周期定案**：停用 = 拒新调用、在跑调用等完（超时击杀兜底）；资源域记账（面板/工具/订阅登记入域），停用整域回收；模型自产插件（`source=model_generated`）走 draft 隔离区——仅当前会话生效、一键转正持久化、权限一律最低。
5. **内置插件试点选型**（实现留 P19）：定 2 个候选——trace 时间线面板（自包含 modal 区，拆分时顺路组件化）与 web_search（已是独立工具）；用两者的需求反推契约字段是否够用，结论写进契约设计说明。
6. **子代理调度草案 v0**（落地留 P22）：子代理 = 独立会话，主会话「一会话一轮」不变量不动；草案含五节——并行度上限、上下文隔离、结果合并、成本归属（子代理花销记父任务）、模型席位（子代理可指定模型）。

## 设计定案（2026-09-19 用户拍板，执行不得推翻）

1. **二合一不是三合一**：MCP 不并入插件——MCP 是公开标准协议、连外部服务，兼容责任在外；插件是本地宿主扩展，兼容责任归我们。工具总线只是内部管道，管道汇合 ≠ 概念合并。对外四词：**Skill / MCP / 插件 / 沙箱**。
2. **插件无类型字段**：manifest 只声明「有什么」（面板、工具、权限），一个插件可同时有面板和工具。报告的界面型/能力型分支作废（实据：board 扩展名义界面型，实有 workspace.write / composer.insert / notify 三能力，分类名不副实）。
3. **source 枚举按二合一修正**：`built_in` / `user` / `model_generated` 三值。报告原枚举（user/mcp/wasm/model_generated）作废——MCP 是一层不是一种来源，WASM 是一种实现不是一种来源。
4. **WASM 降位**：不再叫「WASM 插件」；现有 wasm 工具桥保留工作，定位为插件工具的可选实现 / 沙箱轻量档。本单不动其代码，只改术语与归属。
5. **停用选「等完」**：每会话单轮不变量（steer.rs + `CancelRegistry::try_begin`）下不存在需要杀的长驻任务，为它造任务管理器不值；超时击杀兜底。报告 6.1「杀/等完/挂起三选一」就此定案。
6. **存储收窄两步走**：本单只收会话 + settings（最高频、最敏感）；工作区文件写已有闸门（/api/workspace/file：工作区内 / 512KB / 原子写 / 审计）保持不动；memory/skills 等低频落盘点 P19 顺势收。
7. **钩子与审批门并存**：钩子只有否决权；审批门（`needs_approval_for` 单点 + ChatGate）语义一字不动。钩子的承载形式（建议：配置声明的本地命令，stdin 收 JSON 事件、stdout 回 JSON 决定）由执行定，但「4 挂点 / 仅否决 / 超时放行 / JSONL 审计」四条语义定死。
8. **内置插件不碰执法者**：审批门、存储、并发控制永不插件化（裁判不下场，否则「插件碰不到昨天存下的数据」铁律自破）；试点只选「今天删了明天能重建」的功能。
