> 排期来源：交接文档 §四 P1（2026-09-29 实测：`src/config/settings.rs` 953 行挂 3 个 serde alias 垫片，运行时配置散 5 面）+ §七（动手先立施工单，下一编号 032）。
> 分工（沿用 §五默契）：AI 方落施工单、施工与证据；用户方按本单验收标准逐项收。
> 纪律：窄而刚——垫片退役不等于删兼容：旧字段名兼容**收拢成单一迁移入口**（纯函数 + 单测，沿用仓内 `migrate_provider_keys_to_urls` / `migrate_url_keys_to_configs` / `migrate_legacy_trust_keys` 既有范式），不另起炉灶。

## 一、范围（本单交付）

### A. serde alias 垫片退役（settings.rs，3 处）

| 行 | 旧垫片 | 退役后 |
|----|--------|--------|
| 276 | `#[serde(default, alias = "active_profile_id")]` | `#[serde(default)]`，旧名走迁移入口 |
| 280 | `#[serde(default, alias = "profiles")]` | `#[serde(default)]`，同上 |
| 305 | `#[serde(default, alias = "disabled_extensions", …)]` | `#[serde(default, skip_serializing_if = "Vec::is_empty")]`（P28 垫片一并退役） |

配套：
- 新增纯函数 `migrate_legacy_field_names(&mut serde_json::Value)`——三个旧名一次迁净（新旧并存以新名为准、旧键删除），load 与单测共用同一把尺子；未来改名只在此追加一行。
- 新增 `parse_settings(text)` 唯一解析入口：`Value → migrate → from_value`；`load()` 与全部单测改走它（`from_str::<Settings>` 全仓只此一处生产调用点，实测 grep 已证）。
- 测试改道：`backward_compat_legacy_json_deserialization`（918 行 `from_str` → `parse_settings`）、P28 的 `backward_compat_plugins_rename_migration`（alias 断言改走迁移入口，断言语义不变）。
- 新增 `backward_compat_field_name_migration`：三组旧名各自迁入 + 新旧并存新名优先 + 纯新名原样 + 落盘不再写旧名。

### B. 配置面地图（5 面收敛落档）

**性质先分清（三类，不是五个"配置文件"）**：

| 面 | 性质 | 写入口（grep 实证唯一） |
|----|------|------------------------|
| `config.toml` | 静态种子（随包只读） | 无运行时写（启动一次性读入） |
| `providers.json` | 预设目录（随包只读） | 无运行时写（`gateway::providers::init` 一次性读入） |
| `settings.json` | **唯一运行时用户配置** | `storage::write_settings`（P18 存储一门，原子写 + 审计） |
| `mcp_tokens.json` | 运行时状态·机密（DPAPI 逐条加密） | `src/mcp/oauth.rs` 内部原子写（P28 独立国自持） |
| `plugin_data/` | 运行时状态·插件命名空间 KV | `storage::plugin_write_at` / `plugin_delete_at`（键名白名单） |

- 落档两处：`settings.rs` 模块头（本文件就是 settings.json 的家）+ README 配置节（一行地图 + 指回）。
- 审计口径：每面**写入口唯一**（读侧守卫如 `rules.rs` 的 deny-list 不算写）；审计证据写进施工单，不写"应该唯一"。

## 二、验收标准（用户方逐条收）

1. `grep -n "alias = " src/config/settings.rs` → **0 行**；
2. 旧字段名兼容单一入口：`migrate_legacy_field_names` + `parse_settings` 存在且被 `load()` 与单测共同调用；`from_str::<Settings>` 生产路径仅 load() 一处；
3. `cargo test` 全绿（含新 `backward_compat_field_name_migration` 与改道后的两个旧测试），`cargo clippy` 零告警；
4. 配置面地图在 settings.rs 模块头与 README 各落一份，五个面的写入口与 grep 实证一致；
5. 隔离冒烟（临时目录 + 旧字段名 settings.json 起服务）：服务正常起、`/api/plugins` 200、落盘 settings.json 写新名（`disabled_plugins` 等）；
6. 版本 0.31.0，本地提交（不推送——非 P 级施工单只本地提交）。

## 三、验收标准之外不做的事

- 不物理合并 5 个文件（机密逐条 DPAPI、插件数据按命名空间分目录，合并是倒退）；
- 不动 `providers.json` / `config.toml` 的读取时机（只读种子，动它无收益）；
- 不在 README 堆小字（地图一表 + 指回，写法守 P28 的"不许堆小字"红线）。
