# 030 · P21 成本台账 + 红线收口（用量台账 / 全局花费上限硬闸 / 第三方插件验签）

> 排期来源：ROADMAP「剩余任务清单」第 1 项（P22 子代理的前置——花销归属要靠台账）。
> 验收（ROADMAP 原文）：**按供应商/模型出 token、次数、费用报表；红线 2/3 达成 → 开源窗口**。
> 纪律：窄而刚——台账先把「每一次模型调用都记全」做扎实，报表只出聚合视图；两条红线各自一个硬机制，不做配置平台。

## 一、范围（本单交付）

### A. 用量台账（`src/usage/`）
- **计量收口在网关单点**：`Gateway::stream_chat` / `complete` 是全部模型流量的唯一出入口（主循环、滚动摘要、标题生成、媒体旁路、降级链重试都经它），记录点只放这一处，调用方零埋点。
- 每次调用记一条（JSONL 追加，`<log_dir>/usage/ledger.jsonl`）：
  `ts / session_id / parent_session / purpose(main|summary|title|media) / provider(渠道 host) / provider_id(预设 id) / model / prompt_tokens / completion_tokens / cached_tokens / status(ok|error|cancelled) / latency_ms / error(截断，绝不含 key)`。
- **分计量**：prompt / completion / cache 三路分开（渠道不回 usage 的调用记 0 token 但记请求与延迟，报表可区分「没计价」）。
- **parent_session 字段 v1 恒为 None**（子代理在 P22）——字段先立，P22 子会话填父任务 id 即可按父任务聚合，不做数据迁移。
- **价格表** `prices.json`（app_root，与 providers.json 同规）：`{provider, model, effective_from, prompt, completion, cached}`，单价 = 美元 / 1M tokens；`provider`/`model` 支持 `*` 与 `前缀*`；**带生效时间**——按记录时间取 `effective_from ≤ ts` 的最新一条。缓存命中 token 按 cached 单价计，未命中部分按 prompt 单价。
- **聚合报表** `GET /api/usage?group=provider|model&range=today|7d|30d|all`：分组出 token 三路、请求数、失败数、费用、**延迟分位（p50/p95）**、未计价请求数；设置新增「用量」分区渲染。

### B. 红线 1：全局花费上限（硬闸）
- config.toml `[cost] spend_cap_usd`（默认 0 = 不限）：**累计花费达到即拒绝新的模型请求**（主流程与辅助调用同一道闸），SSE 回人话错误 + `cost.cap_blocked` 审计；调高上限即恢复，不锁死数据。
- 累计值启动时扫一遍台账装入内存，之后随记录增量更新（不每条读盘）。

### C. 红线 3：第三方插件来源验签
- **pin digest 模型**（SSH 主机密钥同款思路，零密钥分发）：插件目录 canonical digest = sha256(排序后的 `相对路径\n + 内容sha256\n` 列表)；`user` 来源插件（ui-ext 工作区/应用根自装、plugins/ 目录形态与裸文件）**必须先被用户 pin 才能加载**。
- 未 pin → 清单里显式「未受信任」+ 拒载（工具不进注册表、面板不服务资产）+ `plugin.trust_blocked` 审计；文件被改 → digest 不符 → 同样拒载并提示「内容已变，需重新信任」。
- 用户点「信任」→ digest 落 settings.json `trusted_plugins{name: digest}` + `plugin.trust_pinned` 审计；**draft 转正自动 pin**（转正是用户显式动作，即信任决定）；`built_in` 与 `model_generated`（draft 隔离区）豁免。

### D. 收尾
- P18 遗留的「budget_exceeded 降级策略留 P21」落地：`[roles] budget` 降级渠道——单任务累计 token 超 `[hooks] budget_tokens` 后，本任务剩余步骤改走该渠道（未配 = 维持主渠道 + Notice，行为与现在一致）。
- README 术语终稿（Skill / MCP / 插件 / 沙箱四词 + 台账/红线说明）、契约文档补验签节、jsonl-schema 补新 kind、ROADMAP 状态更新。

## 二、明确不做（禁止事项）

- 不做子代理本身（P22）；parent_session 只立字段不填值。
- 不做价格抓取/自动同步、不做多币种（单价一律美元 / 1M tokens，用户手填 prices.json）。
- 不做真实密码学签名体系（CA/私钥分发）——pin digest 已覆盖「第三方来源可信」这一红线诉求；manifest 里自称的签名串不采信（无密钥即无意义）。
- 不动审批门/钩子/沙箱任何语义；不改 SSE 既有字段（api_usage 原样）。
- 不动浏览器/桌面壳；不跑真模型计费验证（无渠道 key 时不欠账，如实记录）。

## 三、验证口径

- 单测：价格匹配（生效时间/通配/未命中）、费用公式（缓存拆分）、报表聚合（分组/分位/失败率）、cap 硬闸（未超放行/超了拒+审计）、digest 稳定性与篡改检出、pin/未 pin/改变后拒载矩阵。
- 真机（临时实例 + mock 渠道，照坑 17 流程）：跑几轮对话 → 台账有条、报表数字对得上、设一个极小 cap → 下一次请求被人话拒绝、工作区放个未 pin 插件 → 清单显未信任且工具不出现 → 点信任 → 出现。
- clippy -D warnings 零告警 + 前端构建过 + 全量测试。

## 四、验证记录（真机，2026-09-23；临时实例 + mock 渠道，照坑 17 ④ NO_PROXY）

**台账与计价**：mock 渠道（无 usage）跑一轮 → 台账 1 条（token 0、请求 1、latency 754ms、status ok），报表 `priced:false` + 未计价 1（不静默当 0 元 ✓）。换带回 usage 的 mock（1M prompt / 500K completion / 400K 缓存）+ 全通配价格表（1.0 / 2.0 / 0.1 美元每 1M）→ **费用 1.64 = (600000×1.0 + 400000×0.1 + 500000×2.0)/1M**，与手算一致；按模型分组的行/分位/会话数全对。

**红线一 硬闸**（真机抓到并修掉一个 bug）：`spend_cap_usd=1.0` 重启后第一发**仍被放行**——病根是 `usage::init()` 扫盘计价发生在 `install_prices_file()` **之前**，重启后累计花费从 0 起算。已调整为「先装价格表再 init」（main.rs 有注释）。修复后：重启累计 3.28 正确装入 → 新请求被人话拒绝（「已触发全局花费上限：累计花费 $3.2800 已达到上限 $1.00（config.toml [cost] spend_cap_usd）…」）+ `cost.cap_blocked` 审计 + 台账不增长 → 调高到 10 立即恢复。

**红线二 验签**：工作区放 demo 插件 → 清单 `origin:user / trusted:false / ok:false` + 人话理由 + digest 已算；点「信任」→ ok/trusted、settings.json `trusted_plugins{"ui-ext:demo": <digest>}`、`plugin.trust_pinned` 审计；**改一个字节 → 再次拒载「插件内容已变…重新点信任」**。真机又抓到一个洞：清单拒载了但 `GET /ui-ext/demo/` 仍返回 200（资产分发只查了停用名单）——已在 `serve_ext` 补同一道验签门（复验：篡改后 404 + 人话理由，重新 pin 后 200）。内置 board/trace（built_in）豁免照常加载。

**budget 降级渠道**（P18 遗留收口）：两步 mock + `[hooks] budget_tokens=500000` + `[roles] budget` 指向第二个配置 → 第一步 main-model/9397（1M token）→ Notice「后续步骤改走降级渠道『cheap-model』」+ `cost.downgraded` 审计 → 第二步台账落在 **cheap-model/9399**。顺带补了 `find_channel` 缺失的 B2 key 回落链（环境变量兜底，此前角色渠道一律「API key 未设置」）+ 单测 `resolve_key_falls_back_to_env`。

**回归**：211 单测过 + 2 ignored（+17），clippy -D warnings 零告警，前端构建过，版本 0.23.0。**遗留**：eval 12 任务本轮未跑真模型（无渠道 key；mock 等价链路已过，台账不影响模型行为路径）；prices.json 只带 DeepSeek 样例，StepFun 等渠道单价待用户按公开价目补。
