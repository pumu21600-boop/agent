## 交付

### A. `web_search` 联网搜索（提交 76f9ae5）

- 新增工具 `web_search{query, count?}`（只读 Safe，登记进 KNOWN_TOOLS，登记表断言 9→10）。
- **引擎顺序**：Bing RSS（cn → www）→ Bing HTML（cn → www）→ DuckDuckGo HTML。RSS 是给阅读器
  用的接口，链接是干净真 URL；HTML 版结果链接被包成 `bing.com/ck/a?…u=a1<base64url>`（已实现还原），
  且对程序化客户端可能返回「标题对、结果全是别的东西」的页面——统一加**必须落在 `/search` 结果页**
  的判定（真机踩过：查「rust 语言」返回西班牙股票 / 德国天气）。
- `web_fetch`/`web_search` 共用浏览器 UA 客户端；新增诊断日志 `web.search`（引擎 / 落地 URL /
  页面标题 / 字节数 / 条数）与 `AGENT_WEB_DEBUG_DIR` 原始页落盘开关（排查解析问题用）。
- 单测：Bing HTML 块解析（含 ck/a 跳转还原）、Bing RSS 解析、DDG 跳转还原、实体解码、urlencode 往返。
- 真机：模型调 `web_search` 搜「rust 语言」→ 6 条正确结果（rust-lang.org / 菜鸟教程 / 维基…）。

### B. MCP `resources` / `prompts`（提交 d6e0d6e）

- 客户端：`initialize` 读能力声明；声明了 resources/prompts 才在握手后拉 `resources/list`、
  `prompts/list`（失败不影响上线），缓存进 `ServerState`。
- 合成工具：`mcp__<server>__list_resources` / `read_resource` / `list_prompts` / `get_prompt`
  （服务自己已有同名工具时不覆盖）；调用走本地实现发 `resources/read` / `prompts/get`
  （渲染结果按 `[role] text` 返回；二进制资源只报大小）。
- UI：`/api/mcp` 带出每个 server 的资源/提示词清单，设置→插件 的 MCP 卡片展示。
- 顺手修：HTTP MCP 走环回地址时不再使用**环境代理**（用户挂着代理/VPN 时本机 server 会连不上）。
- 测试：HTTP 端到端（能力 → 合成工具 → 真取到资源正文与提示词渲染结果）+ 无能力时不出合成工具；
  mcp 测试加测试锁（管理器是进程级单例，并行跑会互相清配置）。
- mock（`evals/mcp-http-server.mjs`）补 resources/prompts；真机（隔离实例 + 真模型）：模型
  `read_resource` 读到正文、`get_prompt` 拿到渲染后的提示词并如实作答。

### C. 组件总线 v1（提交 8b55ddc）

- **启停**：`settings.disabled_extensions` + `POST /api/ext/toggle`；停用的扩展不出页面
  （`/ui-ext/...` 404）、不加载 iframe、数据桥不服务；设置→插件 卡片上加开关。
- **manifest 声明**：`ui: [{slot: toolbar|composer, id, title}]` 与
  `permissions: [composer.insert / workspace.write / bus.publish / notify]`（只认白名单，未声明一律拒）。
- **宿主插槽**：声明 `toolbar` 的扩展在顶栏出按钮，点击打开该扩展面板并投递 `agent:slot` 事件。
- **写操作**：`composer.insert`（插进输入框）、`notify`（聊天流系统提示）、`workspace.write`
  （宿主替扩展弹一次确认 → `POST /api/workspace/file`：工作区内、512KB 上限、原子写、JSONL 记
  `ext.workspace_write`）。
- **扩展间通信**：宿主转发 `bus.publish` 给其它已启用扩展（`bus.message`）；为此给已启用扩展挂
  常驻后台 iframe（1px 隐藏），面板打开时自动切换成面板那个。
- 参考扩展 `ui-ext/board` 升级为 v0.2.0：顶栏插槽 + 四个写/总线按钮 + 收 bus/slot 事件演示。
- 真机（浏览器实操）：顶栏出现「项目速览」按钮 → 点击打开面板并投递插槽事件 → 扩展插回一句到
  输入框（composer 里可见）+ 发通知（聊天流可见）；接口层另验：写文件成功、越界路径拒绝、
  停用后 `/ui-ext` 404、重新启用恢复。
