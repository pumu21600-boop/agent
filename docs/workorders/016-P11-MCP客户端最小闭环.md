## 零、现状事实（已核实）

- `src/plugin/mod.rs` 仅占位（总架构 §7 规划注释），MCP/WASM/双总线零代码。
- 工具注册表 `src/tools/mod.rs`：内置 7 工具静态注册，`tools::find`/`tools::execute` 两口。
- 审批单点已就绪：MCP 工具接入只需过 `rules::evaluate_risk` 单点；`KNOWN_TOOLS` 是
  **const 静态表**，未登记工具默认 Dangerous——MCP 动态工具需要动态登记或前缀规则。
- 能力标记（capabilities.tools=false 时不带 tools 参数）闭环已在（012 A3），MCP 工具
  应受同一开关约束。
- 本机有 node 22（可跑官方 MCP server 做冒烟）。

## 一、拟拍板的 3 个决策点（用户定）

1. **分期切法**：016 只做 **MCP client stdio 最小闭环**（本地子进程 JSON-RPC）；
   HTTP/SSE transport、WASM 插件、组件总线（Svelte 插槽）→ 017。是否同意？
2. **首批冒烟 server**：建议官方 `@modelcontextprotocol/server-filesystem`（Node 版，
   限定目录、风险可控、最常用）。用户若有想优先接的 MCP server（自带清单）现在说。
3. **MCP 工具默认审批档**：拟默认 **Normal**（auto 档放行工作区语义、read-only 档弹窗），
   设置里可按 server 整体调档（Normal/Dangerous）；首装该 server 时弹完整工具清单让用户
   确认启用。是否符合预期？

## 二、范围（016 拍板后执行）

- **A. MCP client 核心**（src/plugin/mcp.rs）：
  - stdio transport：子进程 spawn（command/args/env 来自配置）、JSON-RPC 2.0
    （initialize / tools/list / tools/call）、进程崩溃自动标记离线（崩不连坐）。
  - server 配置进 settings.json（`mcp_servers`: [{name, command, args, env, enabled}]，
    向后兼容：字段缺省不影响旧配置）。
- **B. 工具桥接**：发现的 MCP 工具以 `mcp__<server>__<tool>` 命名注册进工具表；
  tools/definitions() 动态包含已启用 MCP 工具（描述用 server 提供的原文）；
  capabilities.tools=false 时同样不带。
- **C. 审批集成**：rules.rs 对 `mcp__` 前缀走新分支——默认 Normal、用户按 server 覆盖档位
  （存 settings）；未确认（首装未确认）的 server 工具一律 Dangerous。
- **D. 设置 UI**：设置新增「插件」分区——server 列表（增删/启停）、接入时展示工具清单
  确认、每 server 档位调整、在线/离线状态。
- **E. 冒烟**：接 filesystem server 实测：发现 N 工具→AI 调用→审批链→结果回喂；
  杀 server 进程验证崩不连坐；重启服务重连。

## 三、明确不在本单

WASM 插件、组件总线（Svelte 插槽）、HTTP/SSE transport、MCP resources/prompts
（只做 tools 子集）、并行调用（P12）。

## 四、验收底线（拍板后细化为可勾选清单）

1. cargo test 基线只增不减；npm run build；真机接 filesystem server 全链路跑通。
2. 崩不连坐：杀 server 子进程，主服务与进行中任务不受影响，状态转离线。
3. 首装确认前 MCP 工具不可被 AI 调用（Dangerous 弹窗或直接不可见，拍板时定）。
4. 断网/ server 无响应有超时（调用不悬挂超过 30s）。

## 五、红线

1. MCP 工具必须走细粒度审批单点（013 A2），禁止旁路。
2. MCP server 的 stdout 是 JSON-RPC 通道，**严禁把 server stderr 之外的内容当工具结果**
   （协议污染）；server 崩溃只标记离线，绝不拖垮主服务。
3. settings.json 语义照坑 14；新增 mcp_servers 字段向后兼容。
4. JSONL 6 类 schema 不动（MCP 调用照 tool_call/tool_result 记录，name 带前缀）。
5. 不内置/不打包任何第三方 MCP server 二进制（用户配置、按需 npx/本地起）。
