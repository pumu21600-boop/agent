## 一、设计取向（v0 边界）

1. **壳与前端解耦**：Tauri WebView 直接加载 `http://127.0.0.1:8321`（runtime URL），
   **前端零改动、不打包进壳**——agent.exe 依旧是唯一真源，壳只是「带托盘的原生窗口」。
2. **服务保活**：壳启动时探测 8321，未起则 spawn `target\release\agent.exe`（等价
   start.bat 内置化）；壳退出**不杀**服务（服务独立生命周期）。
3. **托盘**：左键点击显示/聚焦窗口；右键菜单（打开主窗口 / 退出壳）。
4. **不做**（留口）：安装包打包（msi/nsis 签名分发）、自动更新、开机自启、
   多窗口、壳内扩展 API（组件总线 UI 插槽另议）。

## 二、验收底线

1. `cargo build`（desktop/）产出 desktop exe，双击开窗口显示现有 UI；
2. 托盘可用（显示窗口/退出）；
3. 关掉 agent 服务再启动壳，服务被自动拉起；
4. 主项目（agent.exe/web）零改动。

## 三、红线

1. 壳进程与服务进程完全分离，壳崩溃绝不影响服务与进行中任务；
2. 不引入除 tauri 外的新运行时依赖；图标等资产入 desktop/icons/；
3. 前端/核心逻辑不改（纯加壳）。
