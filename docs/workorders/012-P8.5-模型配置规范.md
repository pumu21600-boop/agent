## A. 必修项（功能残缺/自相矛盾，改到符合规范为止）

**A1 思考形态覆盖的 UI 入口必须恢复**
- 现状：2e211ca 删掉了设置面板的「思考参数形态」控件，但输入栏提示仍写着
  "关不掉到设置改「思考参数形态」（App.svelte L311）——死胡同；后端
  `SettingsUpdate.thinking_style` / `Config.thinking_style` / 探测覆盖链全部健在。
- 规范：中转/反代渠道端点探测**无法保证**认准思考形态（商汤 sensenova 就是
  手动配出 thinking 对象的），用户必须保留手动覆盖手段。设置面板恢复该控件：
  默认「自动（按端点探测）」，显式选择即覆盖；文案注明"中转渠道探测不准时用"。
- 验收：新建 custom 渠道 → 面板选 zai → 商汤式网关 on/off 生效。

**A2 模型能力标记的所有权：用户显式标记 > 推导，推导不得静默覆盖**
- 现状：`pickModel`/`toggleModel`/`selectAllModels` 每次都用 `inferCapabilities()`
  **整体覆盖**用户手动勾选的能力标记——手动给模型标的"图片解析"，重选一次模型
  就被冲掉。
- 规范：推导值只允许在**模型首次成为当前模型且该配置无用户标记历史**时作为初值；
  此后任何模型切换/勾选操作不得改写 `capabilities`。如需重置，提供显式
  「按模型名重新推导」按钮。
- 验收：手动勾选 vision → 切走再切回该模型 → 勾选保持。

**A3 `capabilities.tools` 必须闭环，不许留死控件**
- 现状：UI 有「工具调用」勾选框，后端无任何消费点（grep 全仓只有 context
  breakdown 的统计字段撞名）——勾掉工具调用照样发 tools。
- 规范（二选一，不许维持现状）：(a) 接入语义：`tools=false` 时核心循环不携带
  tools 参数，历史 tool_calls 照常回放；(b) 删除该勾选框。倾向 (a)，能力标记
  的存在意义就是这个。

**A4 角色路由的三种语义必须文案区分**
- 现状：五个角色下拉语义各不相同却共用近似文案——summary/title「跟随主力」=
  主力渠道代跑；vision/video「跟随主力」= 主力具备能力时直连、不具备才转接；
  audio「未配置」= 跳过并注入占位文本。用户无法从 UI 分辨。
- 规范：每个下拉的空选项文案写清各自语义（如 vision 空=「主力不支持图片时才
  需要配置专家」）；`roles.fallbacks` 字段要么接 UI 要么从结构删除
  （`skip_serializing_if`），不许有无入口的静默字段。

**A5 `.attachments/` 必须进工作区 git 排除**
- 现状：媒体附件落在 `<workspace>/.attachments/`，但不在任何 gitignore 提示
  范围——用户在工作区 `git add .` 会把二进制附件提交进历史；影子仓库虽只跟踪
  ls-files，但 agent 的 write/git 工具会看见它们。
- 规范：附件目录落盘时，若工作区存在 git 仓库且 .gitignore 未含该目录，
  自动追加一行 `.attachments/`（只追加，不重写用户文件）。

## B. 语义固化（写进代码注释 + ROADMAP，防止再漂移）

**B1 清除语义（维持现状，成文）**：`0`=清除长度类（context_length/
max_output_tokens）；负数=清除采样类（temperature/top_p）；空串/auto=清除思考类
（thinking/thinking_style）；`clear_key=true`=清 key。P8.3「思考档位被吞」事故
即源于此约定未成文——前后端任何一方改动必须对照本条。

**B2 key 回落链（成文）**：拉模型/发消息的 key 取值顺序 = 请求显式 key >
激活配置 DPAPI key > `DEEPSEEK_API_KEY` 环境变量；key 永不出日志、永不出 JSONL。

**B3 角色解析顺序（成文）**：`settings.roles.<role>` > `config.toml [roles]` >
回落主渠道；角色值按「配置名或配置 id」解析，解析失败回落主渠道并 Notice。

**B4 思考形态解析顺序（成文）**：`Config.thinking_style` 显式覆盖 > 端点探测
（compat.rs：官方域名→native / 本地→local / 其余→openai 兜底）> providers.json
预设 `thinking_format` 兜底。P8.4 词表（含后续追加的 None/claude/moonshot）
只增不改名；新形态入词表必须附真实渠道冒烟记录。
