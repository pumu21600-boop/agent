# 028 · P20.2 内置浏览器对齐 ZCode（协议 / 快照 / 隔离世界 / 驻留 /  screencast）

> 起因：用户告知「zcode 开源了，看一下 zcode 内置浏览器是怎么做的，直接抄到我们的项目就行了」。
> 已查证：ZCode（Z.ai/智谱编程 agent）于 2026-09-20 开源，仓库 https://github.com/zai-org/ZCode ，许可证 **Apache-2.0**。

## 一、ZCode 内置浏览器是怎么做的（精读源码结论）

**双后端架构**（`packages/shared/src/browser-use/` + `packages/desktop/src/main/browserView/`）：

| 后端 | 形态 | 渲染方式 |
|---|---|---|
| `iab`（桌面端默认） | Electron renderer 内 `<webview partition>` 标签 | **网页像素由 guest 直接渲染**（DOM 内合成，可被浮层覆盖） |
| `cdp`（CLI `--browser-use=headless`） | Playwright 启动受管无头 Chromium | 无显示，agent 只拿截图 |
| `extension` | Chrome 扩展 | — |

关键设计（本单移植对象）：

1. **统一命令协议** `browserCommandSchema`（commands.ts，588 行）：一个判别联合（`method`）覆盖全部浏览器动作——navigate/back/forward/reload/snapshot/click/fill/type/press/scroll/hover/select/check/drag/screenshot/getState/elementInfo/evaluate/waitFor + tab 管理（newTab/close/list/activateTab）+ 取消/会话收尾。**Playwright 只是 Tab API 表面，不是后端。**
2. **结构化错误码**：`ref_not_found / navigation_blocked / timeout / capability_unsupported / cancelled / execution_error…`——不静默兜底，明确失败原因给模型。
3. **快照双结构**（snapshot.ts）：`dom`（可见语义节点，只负责"读懂页面"）与 `elements`（可动作元素：ref/tag/role/name/text/value/disabled/checked/selector/xpath/rect/inViewport/parentRef/framePath）分离——防止正文节点占满 action ref 预算；schema 顺序保证工具结果被截断时模型先看到页面语义。
4. **隔离世界执行**：`Page.createIsolatedWorld`（worldName `zcode-playwright-helper`）+ `Runtime.evaluate` 带 `contextId`——DOM 探测/快照在隔离世界跑，页面覆写全局对象或 getter 也改不了结果。
5. **CDP 生命周期纪律**：命令间隙 1.5s 无动作自动 `debugger.detach()`（收窄 Electron 主进程 UAF 崩溃窗口），再次进入命令期恢复式 attach；teardown 等在途命令收敛。
6. **标签页驻留协调器**（browserTabResidencyCoordinator.ts + Policy）：按窗口隔离的 tab 上限与 victim 选择（优先淘汰非选中/不可见/空闲的），suspend/restore 用 generation 计数防迟到 ack；保护态：selected/visible/loading/operation/capture/audible/media/download 一律不淘汰。
7. **截图表协调器**：面板隐藏（0×0）时后台仍可为 agent 截图；人类视口偏好（normal/responsive + zoom）与 agent 固定视口（1280×720）严格分离。
8. **Agent 工作流纪律**（browser-use-plugin skills/control-browser/SKILL.md）：每次操作先 `tabs.list()` 拿全量受控 tab 再校验进入；`goto` 后必 `waitForLoadState(domcontentloaded)`；**每个观察周期最多一个状态变更动作**；同主机名优先复用 tab（`browsers.open(url)`）；基于可见页面状态而非 DOM 源码序做判断。

## 二、对照评估：哪些能抄，哪些抄不了

**抄不了（架构专属）**：`<webview>` 真实像素渲染。那是 Electron 专属能力——ZCode 自己的 Web 端也没有浏览器面板（i18n `browser.desktopOnly`），CLI 端同样只有无头 CDP。我们的形态（Rust 服务 + 系统浏览器前端，desktop 壳也只是加载 127.0.0.1:5173 的 WebView2 窗口）与 ZCode 的 Web/CLI 端同类，**没有等效物**；强求只能整体改 Electron，超出本单范围。

**能抄且价值大（本单落地）**：

| ZCode 设计 | 我们的落地 |
|---|---|
| 统一命令协议 | `src/browser/commands.rs`：`BrowserCommand`（serde `method` 判别）+ 结构化错误码 + `PageState`；工具层五件套合并为一个 `browser` 工具（`method` 枚举），审批门按 method 分级（只读 Safe / 页面操作 Normal，对齐原 browser_open=Safe、browser_click=Normal 的语义） |
| 快照双结构 | 快照 JS 重写：`elements`（+selector/xpath/rect/inViewport/parentRef/disabled/checked，服务端存 ref→selector 映射供 ref 失效后兜底定位）+ `dom` 语义节点；渲染行加视口内外标记 |
| 隔离世界 | `cdp.rs` 增 `evaluate_in_isolated_world`（缓存 executionContextId），快照/定位/求值全部走隔离世界 |
| 截图表协调器 | `Page.startScreencast` 帧流（jpeg q75）→ 每 tab 帧缓冲；面板 `<img>` 改读 `/api/browser/frame`（内存帧，零 CDP 往返，轮询不再每帧全量 PNG 编码）；不可见 tab 自动停流 |
| 驻留/挂起 | 后台（非面板可见、非 agent 页、非加载中）tab 超 60s 空闲且活跃 tab 超上限 4 → `Page.setWebLifecycleState(frozen)`；被访问即解冻恢复。**不做 WS detach**（ZCode 的 detach 是防 Electron UAF，于我们无收益且恢复要重放视口/screencast，风险大）——偏差记录在此 |
| Agent 工作流 | 新增 `skills/browser-use/SKILL.md`（对齐 control-browser 的核心纪律：tabs.list→校验→操作、goto 后等加载、每周期一个动作、同主机复用、基于可见状态判断） |
| 错误码 | 工具结果错误带 `[code] 人话说明`，定位失败时提示用 selector/文本重试 |

**归属**：协议形状、快照结构、驻留策略为自 ZCode（Apache-2.0）设计移植，非逐字复制代码（我们的实现是 Rust，对方是 TypeScript）。本单与 README 记录来源与许可。

## 三、实施顺序

1. `src/browser/commands.rs`（新）：命令枚举 + 错误码 + PageState + 快照结构定义与解析。
2. `src/browser/cdp.rs`：broadcast 事件通道（screencast 帧/dialog 事件分发）+ 隔离世界求值。
3. `src/browser/mod.rs`：快照 JS 升级（elements+dom、selector、inViewport）；统一命令分发（tab 解析：缺省=agent 页，tab_id 可寻址面板页）；驻留状态机（freeze/restore + generation 思路简化为 AtomicBool + 访问即恢复）；screencast 启停（可见 tab 才开）；dialog 捕获。
4. `src/server/webpanel.rs`：`GET /api/browser/frame?id=`（最新 screencast 帧，回落 captureScreenshot）+ `POST /api/browser/activate`（面板可见 tab 上报，驱动 screencast/驻留）。
5. `src/tools/mod.rs`：五件套 → 单 `browser` 工具（method 枚举 + 各方法参数），danger_level=1；dispatch 走 `browser::command`。
6. `src/core/rules.rs`：`browser` 按 method 分级（navigate/back/forward/reload/snapshot/getState/list/newTab/close/activateTab/screenshot/waitFor/hover/scroll=Safe；click/fill/type/press/select/check/drag/evaluate=Normal）。
7. `web/src/App.svelte`：截图 `<img>` 源换 `/api/browser/frame`；面板活跃时 600ms 自动刷新帧（替代动作后手动 `webShotT+=1` 的主路径，动作后仍立即刷一次）；切 tab/开面板上报 activate；加载态用 state 里的 loading。
8. `skills/browser-use/SKILL.md` + 工具描述里引导 `read_skill("browser-use")`。
9. 测试：单测（命令解析/风险分级/驻留 victim/坐标换算）+ 扩 `browser_smoke_local`（ignored 真机：navigate→snapshot→click→fill→scroll→waitFor→tabs list→close）；clippy -D warnings。
10. 真机：按固定流程 `stop → cargo build --release → start`（防 exe 锁掩盖失败），curl /api/version 确认新版本；浏览器实操面板（导航/点击/滚动/多 tab/挂起恢复）；临时实例 + mock 渠道驱动 agent 走 `browser` 工具全流程。
11. ROADMAP 记 P20.2 + 本单归档；P 级收尾提交并推送 origin dev。

## 四、验收口径

- 面板：任意站点可显示；点击/滚动/输入后 ≤1s 内画面更新（不再依赖动作后一次性截图）；切走的面板页停止出帧（CPU 回落）；后台 tab 被挂起、切回自动恢复且视口/标题不丢。
- agent：一个 `browser` 工具覆盖 open/snapshot/click/type/fill/press/scroll/select/check/hover/drag/evaluate/waitFor/screenshot/tabs；只读方法不弹审批、页面操作方法弹审批（与原语义一致）；ref 失效能用 selector/文本兜底；alert 类弹窗不卡死（getDialog/handleDialog）。
- 快照：带 selector/xpath/rect/inViewport/parentRef；正文节点不占 ref。
- 隔离世界：页面预置 `document.querySelector = () => { throw 1 }` 后快照仍成功。
- 测试全绿 + clippy 零告警 + 前端构建过。

## 五、验收结果（2026-09-21 真机）

- **单测/clippy/构建**：主 bin 193 过 + 2 ignored（含 `browser_smoke_local` 真机冒烟：navigate→语义 click→fill→select→wait_for→scroll→get_state→list→evaluate 全过）、eval 5 过、clippy -D warnings 零告警、前端构建过。版本 0.21.0。
- **mock 全链路**（临时实例 + mock 渠道，剧本「浏览」）：`navigate` → `click{text:"Learn more"}` 语义定位真实跳到 iana.org → `snapshot` 复核 → `close_browser` 进程真退出（JSONL `browser.close reason=tool`，msedge 进程数归零）。auto 档零审批卡（与原 click=Normal 语义一致）。
- **面板**：`/api/browser/frame` 返回 screencast JPEG（内存直出）；视口 500×700 覆盖生效；JS 弹窗捕获后面板出「确定/取消」条、处理后帧流恢复。
- **驻留**：活跃页超上限 4 时最旧空闲后台页 suspend（agent 页永保护），activate 后 restore、URL 保留。
- **隔离世界硬验证**：fixture 页把 `document.querySelector/querySelectorAll` 全废掉，快照/定位/求值依然完整（主世界执行必抛 hacked）。
- **真机坑（本机实情）**：用户机器**没装完整版 Edge/Chrome**，界面本身跑在 WebView2 里——浏览器发现链补扫 `Program Files (x86)\Microsoft\EdgeCore\<版本>\msedge.exe`（实测该运行时能 `--headless=new --remote-debugging-port` 起无头 CDP，HeadlessChrome/153）；另本机直连外网不通、须走系统代理（代理抽风时无头页会拿 chrome-error，属环境问题非代码问题）。
- **偏差记录**：ZCode 的 CDP 空闲 1.5s detach（防 Electron UAF）未移植——我们长连接复用，无对应崩溃窗口；驻留用 freeze（Page.setWebLifecycleState）而非 WS detach，恢复零重放成本。
