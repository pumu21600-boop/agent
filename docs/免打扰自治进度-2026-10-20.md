### 本轮修了 4 个真问题

1. **断点兜底缺失**（anthropic.rs `mark_last_block`）：末块是未来新块型
   （document 等）时断点三被静默丢弃。改为**反向扫描**最后一个可缓存块

2. **空串尾部不打点**：末条 user 消息为空串时跳过断点。改为也包成 text 块
   打点（空 text 块合法），保前缀锚。
3. **插件工具顺序 bug**（wasm.rs，实锤）：`load_inline`（draft 插件装载）把条目
   push 到注册表末尾，而 `tool_definitions()` 按注册表原序下发——draft 一装载，
   tools 数组顺序变，Anthropic 的 system→tools 稳定区前缀作废、缓存全丢。
   修：下发前按 stem 排序（与 MCP 侧同规）+ load_inline 后重排（双保险）。
   新增测试 `tool_definitions_sorted_by_stem`（乱序塞注册表 + 加载失败过滤）。
4. **「项目现状」brief 打破第 2 轮缓存**（turn.rs，e2e 实锤）：brief 只在新会话
   第一轮的系统提示末尾出现 → 第 2 轮 system 比第 1 轮短一截 → system+tools
   整段稳定区三个断点全 miss。隔离实例 e2e 实测：第 2 轮命中 **21%**（第 3 轮起
   才回 99%）。修：brief 从系统提示搬出，**并进首条 user 消息**
   （`inject_brief_into_first_user`，6 个单测覆盖：空 brief/字符串/多模态数组/
   只碰首条/无 user/null content）。/api/chat 与无头会话同一路径。
   **修复后 e2e：第 2 轮 21% → 98%，全会话 98-99%。**

- **实时条**：聊天区输入框上方（主区内），有排队/执行中的派发才占位。每行：
  状态徽章（排队中/执行中）+ 标签 + 单发取消（×）。终态即撤。
- **回看面板**：居中小弹窗（插件制作器同款形态）。本会话全部派发：徽章

### 后端（src/server/subagent.rs）

- dispatch id 提前发号，queued/spawned/done/cancelled 全生命周期共用。
- **排队即上屏**：满员等待时历史记 queued + UI 推一条（不再干等）。
- **历史环形缓冲**（200 条，新→旧）：queued→running→终态同一段就地更新。
  为什么服务端着账：SSE 只推当时开着的页面，刷新/重开就丢，跑完的要能回看。
- `GET /api/subagents`（历史）+ `POST /api/subagents/cancel`（按 dispatch id
  单发精确取消；级联取消仍走父任务停止键）。
- 子代理生命周期事件经 ui_events 总线推前端（spawned/done/cancelled；
  queued 的 200ms 轮询审计事件不推，避免刷屏）。
- 修了一个自己引入的 bug：没排队时历史记录从未入队（只有 queued 分支 push），
  补 push 后两条路径汇到同一段记录。
- 测试 7 项（含新增 4 项）：历史生命周期就地更新、容量边界丢最旧、

## 第 3 轮：抓取网页增强（2026-10-20 完成）

### 考察结论

功能本来就有（用户以为没做）：web_fetch（静态 HTML→正文）+ web_search
（Bing RSS/HTML + DDG 五引擎，SSRF 逐跳闸）+ browser 工具（完整 CDP 控制）。
**真缺口**：web_fetch 遇到 JS 渲染的 SPA 页只会报错「本工具不做 JS 渲染」，
而浏览器明明能渲染——中间没有桥。用户体感就是「抓取网页没做」。

### 改动

- **web_fetch 加 render 档**（src/tools/web.rs）：auto（默认）= 静态优先，
  取到正文薄（HTML 且 < 200 字 = JS 骨架）或空 → **自动回落浏览器渲染**
  （navigate + 新方法 page_text 取 innerText）；always = 直接浏览器；
  never = 只要静态（浏览器插件停用时的显式选择）。回落前过同一道 SSRF 闸。
- **浏览器新方法 page_text**（src/browser/）：document.body.innerText 整页
  正文，上限走 max_chars——evaluate 的输出钉死 2000 字符，抓长文不够。
  登记进 ALL_METHODS + 只读表（审批门自动归 Safe）。
- 回退失败时说两句实话：人话指引（换 browser 工具/去设置开插件），
  不让模型以为功能坏了。
- 测试：回退判定纯函数（空/薄 HTML 回落、非 HTML 不回落）+ render 档解析
  （大小写/空白/缺省）+ page_text 登记与解析，共 5 项新用例。

### e2e（隔离实例 + mock + Tabbit 无头）

mock 加 SPA 演示页（静态空壳 + JS 水合正文）与静态演示页 + 「抓取 <url>」剧本：

- SPA 页 auto：静态只拿到「加载中…」壳 → 自动起浏览器 → 拿到水合后的
  完整正文（带「这是 JS 渲染页面」前缀标记）；
- 静态页：403ms 直达，**不起浏览器**；
- SPA 页 render=never：返回薄壳，不起浏览器（显式 opt-out 有效）；
- 浏览器不可用（无壳未开无头闸）：错误带人话指引（首轮实测过这条路径）；
- 无头浏览器用 AGENT_BROWSER_HEADLESS=1 + AGENT_BROWSER_PATH 指 Tabbit
  （用户「不起 Edge」规矩的产品化双重闸，本机无下载）。
- 进程收尾：无头浏览器随 agent 死亡被 jobguard 保险丝收掉，零残留。
